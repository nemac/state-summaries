
## Third iteration of NCA sandbox

To install
```
npm install
```

To Build dist package
```
npm run build
```

To run dev server
```
npm start
```

## Branches and deploys

- Open pull requests into `develop`. Each merge deploys to https://data-explorer-dev.nemac.org.
- To release, open a pull request from `develop` into `master`. Each merge into `master` deploys
  to production at https://data-explorer.nemac.org.
